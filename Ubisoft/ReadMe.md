How to use.

Make file called tester.txt put one random invalid email:pass in it (Used to mass scan unblocked proxies on datadome/Ubisoft's Captcha)

Make a file called accounts.txt and put your email:pass combo list it it

Make a file called proxies.txt and put your proxies in the file using this format http://user:pass@ip:port

Run with node ubitra.js
